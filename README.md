Este projeto investiga por que os clientes cancelam o serviço de uma operadora de telecom. Partindo de um dataset público do Kaggle, fiz a limpeza e a transformação no Power Query e montei um modelo de dados com tabela fato e dimensão. No Power BI criei medidas em DAX e um dashboard com indicadores de clientes ativos e cancelados, taxa de churn e tempo médio de permanência.

Também desenvolvi uma versão web interativa, sem servidor, em HTML, CSS e JavaScript. Ela tem gráficos de colunas 3D em SVG e filtros combináveis entre dimensões, como tempo de casa, contrato, forma de pagamento, internet, suporte técnico, idade e dependentes.

Das 7.032 contas analisadas, 1.869 cancelaram (26,6%). Os resultados mostram que o churn é muito maior nos primeiros 6 meses de relacionamento, nos contratos mensais, na internet por fibra óptica e entre quem paga com cheque eletrônico. Já contratos longos e o suporte técnico estão associados a muito menos cancelamentos.
